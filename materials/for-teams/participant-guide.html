1 Welcome & Objective

Welcome to the QA Hackathon 2026! This is your chance to push beyond traditional QA — leveraging AI tools to test smarter, faster, and more creatively.

You'll be given a Clinic Appointment & Patient Management System (MediCare Clinic). Your mission: find bugs, write test cases, automate UI tests, and present your strategy — all within 90 minutes.

💡 Key Goal: Demonstrate how AI tools can accelerate QA activities — bug discovery, test case writing, data generation, automation scripting, and reporting.

2 The System: MediCare Clinic

MediCare Clinic is a web-based clinic management application with the following modules:

Core Features

  • Authentication & User Management — Patient registration, login, password reset, role-based access
  • Patient Management — Patient profiles (personal info, medical history, insurance), search, edit
  • Appointment Booking — Select doctor, date & time slot, view availability, cancel/reschedule
  • Doctor Dashboard — View today's appointments, add prescriptions/notes, mark complete
  • Admin/Receptionist Dashboard — View all appointments, manage doctors, reports
  • Billing — Generate invoices, apply discounts, payment status tracking

User Roles

RoleAccess
PatientRegister, book/cancel appointments, view own history, view invoices
DoctorView schedule, manage appointments, add prescriptions/notes
Receptionist/AdminManage patients, manage doctors, view all appointments, billing

Technical Details

  • Frontend: Web application (accessible via browser)
  • Backend: REST API with full Swagger/OpenAPI documentation
  • Database: Pre-seeded with sample data (doctors, patients, appointments)

5 Bug Categories to Explore

The application may contain issues across these categories. Think broadly!

CategoryWhat to Look For
Functional Features not working as expected, incorrect calculations, validation issues, workflow breakdowns, boundary/edge case failures
Security Authorization flaws, injection vulnerabilities, sensitive data exposure, authentication weaknesses, access control issues
Performance Slow page loads, inefficient data fetching, missing pagination, operations that don't scale, resource-heavy queries
Usability Poor user feedback, confusing workflows, missing confirmations, unhelpful error messages, accessibility gaps
Data Privacy Unnecessary data exposure, insufficient access controls on sensitive data, data leaks in APIs, missing audit trails, improper data handling
💡 Tip: Use AI tools to help you think about edge cases, review API responses for data leaks, generate test data for boundary conditions, and identify potential security vulnerabilities.

12 Frequently Asked Questions

Can we modify the application code to fix bugs?

No. You are testers, not developers. Find and report bugs — don't fix them.

Can we access the application source code?

No. The application is centrally hosted. You should test it as a black-box through the UI and API (Swagger docs are available). This simulates a real-world QA scenario where you test without seeing the code.

What if I can't access the application URL?

Contact the organizers immediately via the support channel. They will help resolve connectivity issues.

Can we write automation tests in any programming language?

Yes. Use whatever language/framework you're comfortable with. Just make sure the tests are runnable with clear instructions.

Do we need to automate ALL scenarios?

No. Focus on happy-path scenarios for automation. Quality over quantity — a few well-written, passing tests score better than many broken ones.

Can we split the CSV templates across multiple team members?

Work however you want, but submit ONE final bug-report.csv and ONE final test-cases.csv per team. Merge before submitting.

Will we get the API documentation in advance?

The Swagger documentation is available within the running application at /api-docs. You'll access it once you connect to the centrally-hosted app during the event.

What counts as "AI Tool Usage" for scoring?

Using AI for: generating test cases, writing automation code, reviewing code for bugs, generating test data, creating reports, analyzing API responses, or anything creative. The more tasks you accelerate with AI, the better.
